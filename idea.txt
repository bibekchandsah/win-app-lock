1. Kill the stuck build processes
taskkill /F /IM MSBuild.exe /IM makepri.exe /IM AppLock.exe

2. Check for unexpected folders inside src\AppLock\
Get-ChildItem -Path "src\AppLock" -Directory | Select-Object Name

Inside src\AppLock\, you should only see standard source folders:
  Models
  Services
  ViewModels
  Views
  icons

If you see any extra folders (like bin-verify, backup, temp-bin, etc.), delete them immediately:
cmd /c "rmdir /s /q src\AppLock\EXTRA_FOLDER_NAME"

3. Clean bin and obj
Wipe the generated binaries so MSBuild starts with a clean slate:
cmd /c "rmdir /s /q src\AppLock\bin & rmdir /s /q src\AppLock\obj"

4. Rebuild
.\build-with-msbuild.ps1
or:
dotnet build src/AppLock/AppLock.csproj -c Release
